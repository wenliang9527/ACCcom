# 管理功能

ACCCOM 提供了书签、预设、快捷键和设置等管理功能，帮助用户组织串口调试工作流。

## 书签管理

`BookmarkManager` 在收发数据中标记关键条目，方便快速定位：

- **添加/删除**：按条目 ID 添加书签，自动记录方向、时间戳、预览文本
- **导航**：支持上下导航跳转到对应书签条目
- **UI 绑定**：与 UI 书签列表双向绑定（`ObservableCollection<BookmarkItem>`）

## 预设管理

`PresetManager` 管理串口配置预设，持久化到 `presets.json`：

- **保存/加载**：保存串口配置组合（端口、波特率、数据位、停止位、校验位、DTR/RTS）
- **快速切换**：快速切换不同设备的配置方案

## 快捷发送侧边栏

快捷发送以**右侧侧边栏**形式提供（工具栏「快捷」按钮或 **Ctrl+Q** 开关；收起后右侧留 28px 竖条，点击展开；宽度可拖拽调节，限制在 180–420 px），支持**分页管理**：

### 页管理

| 操作 | 方式 |
|------|------|
| 翻页 | 侧边栏顶部 ◀ / ▶ 按钮，或页名下拉框直接选择 |
| 新建页 | 页导航栏 **+** 按钮 |
| 重命名当前页 | 页导航栏 **⋯** 菜单 → 重命名当前页 |
| 删除当前页 | ⋯ 菜单 → 删除当前页（非空页需确认） |

- 每页独立命名（如"AT 命令"、"Modbus"、"自定义协议"），页数无限制
- `Alt+1`~`Alt+9` 作用于**当前可见列表**（启用过滤时为过滤后的前九条，与行上 AltN 标签一致）

### 导入 / 导出

配置可导出为 JSON 文件，换电脑直接导入即可恢复，无需重复配置：

| 操作 | 说明 |
|------|------|
| 导出全部 | 底部"导出全部"按钮，保存所有页及指令 |
| 导出当前页 | ⋯ 菜单 → 导出当前页，仅保存该页 |
| 导入 | 选择导出的 JSON 文件后可选：**合并**（追加到现有页之后，重名自动加后缀）或**替换**（覆盖现有全部页） |

### 指令操作

| 操作 | 行为 |
|------|------|
| 单击指令行 | 延迟约 220 ms 后发送（避免双击编辑时误发） |
| 双击指令行 | 编辑该指令（名称/命令/HEX 模式），不触发发送 |
| 右键指令行 | 发送 / 填入发送框 / 复制 / **循环发送** / 上移 / 下移 / 切换 HEX / 编辑 / 删除 |
| `Alt+1`~`Alt+9` | 快捷发送**当前可见列表**第 1~9 条指令 |
| `Ctrl+Q` | 开关快捷发送侧边栏（也可点工具栏「快捷」或右侧竖条） |
| 窄窗口 | 工具栏/连接参数/发送栏/侧栏页导航与页脚均为 **WrapPanel**，按钮换行而非被裁掉；主内容列最小 480 px |
| 搜索框 | 按名称**或命令内容**过滤（不区分大小写）；Esc 清空，↓ 进入列表，↑ 返回搜索框 |
| 删除指令 | 需确认（与删除页一致） |

- **类型标识**：指令行左侧圆点标记类型 —— 蓝色为文本，琥珀色为 HEX
- **第二行预览**：显示命令体（HEX/文本），悬停 ToolTip 可见完整内容
- **填入发送框**：右键"填入发送框"可先修改参数再手动发送
- **新指令插入位置**：若列表有选中项，插入选中项之后；否则追加到页尾
- **计数**：标题栏显示当前页指令数；过滤时显示 `可见/总数`

### 循环发送（与发送栏合并）

两种入口，同一套机制（发送栏「循环 + 间隔 + 来源」）：

1. **右键指令 → 循环发送**：填入发送框并打开循环，来源下拉同步选中该指令
2. **发送栏来源下拉**：「发送框」或任意页任意指令；选中即填入，循环已在跑则立即按新内容发送

- **唯一间隔入口**：发送栏「循环 + 间隔(ms)」；Esc 或「停止」结束
- **最小间隔**：`min_ms = ceil(字节数 × 10 × 1000 / 波特率) + 1`（8N1，10 bits/字节，含 1 ms 定时余量）；间隔低于下限时自动钳制，ToolTip 显示当前最小值
- 波特率取串口当前速率；端口未打开时回退到连接面板所选波特率
- 循环内容 = 发送框当前文本（可继续手改）；网络桥接已连接时优先走网络桥

## 设置管理

`SettingsService` 管理应用全局设置，持久化到 `settings.json`：

- **加载/保存**：读写 `AppSettings` 配置对象
- **容错机制**：文件损坏时自动回退到默认设置
- **全局配置**：覆盖主题、语言、缓冲区大小等全局选项
