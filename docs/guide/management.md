# 管理功能

ACCCOM 提供了书签、预设、快捷键和设置等管理功能，帮助用户组织串口调试工作流。

## 书签管理

`BookmarkManager` 在收发数据中标记关键条目，方便快速定位：

- **添加/删除**：按条目 ID 添加书签，自动记录方向、时间戳、预览文本
- **导航**：支持上下导航跳转到对应书签条目
- **UI 绑定**：与 UI 书签列表双向绑定（`ObservableCollection<BookmarkItem>`）

## 预设管理

`PresetManager` 管理串口配置预设，持久化到 `presets.json`：

- **保存/加载**：保存串口配置组合（端口、波特率、数据位、停止位、校验位、DTR/RTS）
- **快速切换**：快速切换不同设备的配置方案

## 快捷发送侧边栏

快捷发送以**右侧侧边栏**形式提供（工具栏 ☰ 按钮可开关，宽度可拖拽调节），支持**分页管理**：

### 页管理

| 操作 | 方式 |
|------|------|
| 翻页 | 侧边栏顶部 ◀ / ▶ 按钮，或页名下拉框直接选择 |
| 新建页 | 页导航栏 **+** 按钮 |
| 重命名当前页 | 页导航栏 **⋯** 菜单 → 重命名当前页 |
| 删除当前页 | ⋯ 菜单 → 删除当前页（非空页需确认） |

- 每页独立命名（如"AT 命令"、"Modbus"、"自定义协议"），页数无限制
- `Alt+1`~`Alt+9` 作用于**当前页**的前九条指令

### 导入 / 导出

配置可导出为 JSON 文件，换电脑直接导入即可恢复，无需重复配置：

| 操作 | 说明 |
|------|------|
| 导出全部 | 底部"导出全部"按钮，保存所有页及指令 |
| 导出当前页 | ⋯ 菜单 → 导出当前页，仅保存该页 |
| 导入 | 选择导出的 JSON 文件后可选：**合并**（追加到现有页之后，重名自动加后缀）或**替换**（覆盖现有全部页） |

### 指令操作

| 操作 | 行为 |
|------|------|
| 单击指令行 | 立即发送 |
| 双击指令行 | 编辑该指令（名称/命令/HEX 模式） |
| 右键指令行 | 发送 / 填入发送框 / 编辑 / 删除 |
| `Alt+1`~`Alt+9` | 快捷发送当前页第 1~9 条指令 |

- **类型标识**：指令行左侧圆点标记类型 —— 蓝色为文本，琥珀色为 HEX
- **填入发送框**：右键"填入发送框"可先修改参数再手动发送

## 设置管理

`SettingsService` 管理应用全局设置，持久化到 `settings.json`：

- **加载/保存**：读写 `AppSettings` 配置对象
- **容错机制**：文件损坏时自动回退到默认设置
- **全局配置**：覆盖主题、语言、缓冲区大小等全局选项
